## 机理常数（跨实验复现）

- **每次 cache 命中 ≈ 省一次完整 forward**：4 步路线 ~60s/次、8 步路线 ~75s/次
- i2v 固定开销（首帧条件编码 ~80s）不参与缓存——**镜头越贵，T8 绝对省得越多**（t2v 省 120s、i2v Turbo 省 157s、i2v PDD 省 203s）
- 官方参照系：一般环境跑同规格 20–30 分钟/镜 → 本手册最快档 **快 6–9 倍**（192s vs 1200-1800s）

## 方法论备注（复现者的注意事项）

1. 计时口径：热运行 wall-clock（模型已驻留显存），从 `/prompt` 提交到 history success——含 VAEDecode/封装，不含模型冷加载（冷启动另计 40-60s）
2. prompt_id 确定性：同输入重提会被静默去重——A/B 实验改任何参数（哪怕 cache_device）都会生成新 pid，这是特性不是坑
3. 速度数据的环境敏感性：并发 HTTP 轮询过频或后台重负载可致 ±10% 漂移；**命中数（cached X/N）不受环境影响**，是最可靠的对比维度
4. 盲测方法论：同 seed 同 prompt 的两条片匿名随机排序（key 藏文件），人眼选优——用于 PDD vs Turbo 成片画质裁决
