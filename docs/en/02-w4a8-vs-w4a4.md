# 02 · Quantization Measured: W4A8 vs W4A4

## The Verdict First

**The DiT must run INT8 (W4A8).** On a 2080Ti 22G, W4A4 is not "slightly worse" — it is **unusable**.

## The Error Data

Quantization reconstruction errors measured by the community on the same 2080Ti 22G card:

| Route | Reconstruction error | Picture |
|---|---|---|
| W4A4 (4-bit weights + 4-bit activations) | 0.2005 | **Color tearing**, unusable |
| W4A8 (4-bit weights + INT8 activations) | 0.0110 | Normal |

An 18× error gap. Why: Turing has no FP8/BF16 tensor cores, so once activations drop to 4 bits there is no high-quality compute path to fall back on.

## This Box's Production Numbers (W4A8 fast route)

Config: 640×352 · 124 frames · 4 steps · native audio

| Metric | Value |
|---|---|
| Nominal production speed | **8.5 min/clip** |
| Measured best | **3.5–4 min/clip** (warm cache) |
| GPU utilization | 100% |
| VRAM | 22084 MiB / 22542 MiB |
| End-to-end smoke (incl. first model load) | seed=3010, ~6 min to success |

Batch measurement (consecutive clips in one session): A = 5 min, B = 6 min, C = 33 min — C's extra 27 minutes was abnormal initialization (see the antivirus/staging entry in [06 FAQ](06-faq.md)); sampling itself is only 91 s/step.

## The Ceiling Reference from Another Card

Another 2080Ti 22G owner's long-clip result, as an upper-bound reference for this card:

- Config: INT8 DiT (19.5G resident) + W4A4 text encoder + dual VAE
- Output: **15 s, 362 frames, 1080p with audio = 23 min 03 s**
- Details: 20-step sampling at 88.87 s/step, generated at 960×540 → RTX VSR upscale to 1080p

Two takeaways: ① at 20 steps each step costs 88 s — step count scales total time linearly, so **if you can use the 4-step Turbo route, don't go 20**; ② that "1080p" is post-processed upsampling, not native generation — see the RTX VSR entry in [04 Community tips](04-community-tips.md).

## You Can Try Without 22G

A stock 2080Ti 11G: the W4A8 DiT weights alone squeeze into 11G for short 480p clips, but it needs a more aggressive offload configuration and speed drops noticeably. Import the compat workflows from this repo and try directly; on OOM, turn resolution and frame count down.
